## 📋 Project Features & Requirements Checklist
This webpage was created according to strict HTML5 markup and accessibility guidelines:

- **Document Structure**: Includes `<!DOCTYPE html>`, `<head>`, `<title>`, and `<body>`.
- **Semantic Tags**: Uses semantic HTML5 elements including `<header>`, `<main>`, and `<footer>`.
- **Heading Hierarchy**: Uses structured headings (`<h1>` followed by `<h2>`) without skipping levels to comply with accessibility standards.
- **Content Requirements**:
  - An unordered list (`<ul>`) containing at least 3 item entries.
  - 3 images (`<img>`) with meaningful, descriptive `alt` attributes.
  - An external source link (`<a>`).
- **Validation**:
  - Validated with the [W3C Markup Validation Service](https://validator.w3.org/).
  - Verified accessibility compliance using the [WAVE Evaluation Tool](https://wave.webaim.org/).
